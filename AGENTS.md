# Instrucciones de desarrollo

## Tecnologías

- Utilizar HTML y CSS estándar para este proyecto.
- No introducir dependencias ni frameworks sin aprobación.
- Mantener los archivos existentes y su organización.

## Interfaz

- Priorizar mobile-first.
- Utilizar HTML semántico.
- Mantener la identidad visual actual.
- Usar clases BEM en los componentes nuevos.
- Evitar anchuras fijas que provoquen desbordamientos.

## Procedimiento

- Leer los archivos relevantes antes de proponer cambios.
- Explicar brevemente el problema y la solución prevista.
- Realizar modificaciones delimitadas.
- No afirmar que se ha probado una página sin haberla abierto o ejecutado una comprobación real.
- Resumir los archivos modificados y las pruebas pendientes.
